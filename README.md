# Izu Pets - Pet-Friendly Travel Guide

A comprehensive pet-friendly travel blog focused on the beautiful Izu Kogen area in Japan. Discover the best pet-friendly restaurants, hotels, parks, and activities that welcome your furry friends.

## Features

- **Pet-Friendly Spot Directory**: Find restaurants, hotels, parks, and activities that welcome pets
- **Multilingual Support**: Available in both English and Japanese
- **Detailed Information**: Pet fees, restrictions, features, and contact information
- **User-Friendly Design**: Easy navigation for users of all ages
- **Pet-Friendly Features**: Search by pet-friendly amenities and services

## Tech Stack

- **Frontend**: Next.js 14 with TypeScript
- **Styling**: Tailwind CSS with custom pet-friendly color scheme
- **CMS**: Sanity.io for content management
- **Internationalization**: next-intl for multilingual support
- **Icons**: Lucide React for beautiful, accessible icons

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables
4. Run the development server:
   ```bash
   npm run dev
   ```

## Content Structure

- **Pet-Friendly Locations**: Restaurants, hotels, parks, activities, cafes, beaches, hiking trails, pet stores, veterinary clinics, and grooming salons
- **Pet Activity Types**: Categories for different types of pet-friendly activities
- **Multilingual Content**: All content available in English and Japanese

## Design Philosophy

- **Pet-Friendly Colors**: Soft browns, gentle greens, and playful blues
- **Accessible Design**: Easy to navigate for users of all ages, including seniors
- **Inclusive Content**: Welcoming to all pet owners and their companions
